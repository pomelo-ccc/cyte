### What's New in Cyte 2.0.2

- **Native Tencent CodeBuddy (`codebuddy` / `cbc`) Engine**: Persistent multi-turn `stream-json` sessions supporting CN (`copilot.tencent.com`), Global (`www.codebuddy.ai`), iOA, Enterprise, and custom `~/.codebuddy/models.json` models with `--effort` and `--autocompact`.
- **Multi-Account OAuth & Credit Center**: Browser OAuth login for CN & Global accounts, API Key accounts (`CODEBUDDY_API_KEY`), Token/JSON import & export, live edition/billing checks, per-turn credit tracking, and automatic failover.
- **Refined Workbench & Multi-Platform Releases**: Minimalist thin-stroke sidebar, warm unified composer card with icon-only mode picker and crisp context ring, custom theme editor, and Ed25519-signed installers for macOS, Windows, and Linux.

> **macOS First Launch Note**: On macOS without Apple notarization, run `xattr -cr /Applications/Cyte.app` once in Terminal after dragging `Cyte.app` into `Applications` if Gatekeeper blocks first launch.
