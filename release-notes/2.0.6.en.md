### Bug Fixes
- **Fixed Tool Permission Approvals Failing with `Permission denied by SDK`**:
  - Translates `can_use_tool` `control_response` payloads (`behavior: 'allow' | 'deny'`, `message`) into CodeBuddy CLI `SdkPermissionClient`'s required `allowed: true | false` and `reason` fields.
  - Injects session-level `Always allow <Tool>` suggestions on incoming `can_use_tool` requests and auto-approves subsequent calls in the session once granted.
  - Passes native `-y --permission-mode bypassPermissions` directly to CodeBuddy CLI in Full Access mode, synchronizes pre-session `set_permission_mode` changes once `session_id` is established, and maps `elicitation_create` control requests.
  - Restores `image_blob_ref` image attachments when reading historical CodeBuddy `.jsonl` sessions.
