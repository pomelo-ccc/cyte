更新日志

BaoCode 每个版本的变化。

2.0.5

问题修复

  • 修复会话恢复/重连时历史用户消息重复渲染：在 initialize 握手中携带 hasPrompt: true，并增加 --resume 启动历史回放（renderHistory）与迟到 isReplay 回显帧的多重拦截，彻底消除恢复会话、标签页唤醒或切换账号时在底部重复追加整段历史用户消息的问题。
  • 完整支持 CodeBuddy .jsonl 本地会话读取与恢复：兼容 ~/.codebuddy/projects/*.jsonl 的会话记录结构（消息、思考链、工具调用与返回、会话自定义标题及每轮消耗积分），重启应用后侧边栏会话列表与历史记录完整展示不丢失。

2.0.4

新增与优化

  • 思考强度 100% 对齐 WorkBuddy：实时拉取 get_available_models.rawModels，按官方规则支持 思考模式 开关及 低 / 中 / 高 / 超高 / 极致 五档思考强度，模型菜单右侧同步展示积分消耗倍率（如 0.29x、0.00x）。
  • 当前账号剩余积分实时展示：对接官方 get-user-resource-summary 与企业计费接口，在输入框工具栏胶囊与账号弹窗中直接显示当前账号剩余积分、总额度进度条及各资源包明细。
  • 每次对话消耗积分展示：每轮对话结束在消息底部统计栏直接显示 消耗 x.xx 积分，并在上下文用量弹窗同步汇总会话消耗积分。

问题修复

  • 修复 CodeBuddy CLI 在 --replay-user-messages 模式下回显 UUIDv7 导致发送消息显示两条重复气泡的问题。

2.0.2

Cyte 2.0.2 更新说明

  • 原生对接腾讯 CodeBuddy (codebuddy / cbc)：常驻多轮 stream-json 进程直连，完整支持中国版 CN（Hunyuan 2.0、GLM-5.1、DeepSeek V3.2、Kimi K2.5、MiniMax M2.5）、国际版 AI（Claude 4.6、GPT-5.4、Gemini 3.1）、iOA、企业专享版及 ~/.codebuddy/models.json 自定义模型。
  • CodeBuddy 多账号 OAuth 与积分中心：内置中国版 / 国际版官方浏览器 OAuth 授权、API Key 账号、Token/JSON 批量导入导出、套餐查询、实时每轮 Credits 统计与配额耗尽自动切号。
  • 温润极简工作台与全平台签名安装包：极简细线条侧边栏、纯图标模式选择器、高对比上下文进度环、自定义主题工坊，以及 macOS / Windows / Linux 全平台签名自动更新包。

macOS 首次打开提示：若未配置 Apple 开发者公证，其它 Mac 下载拖入 Applications 后若提示无法打开，在终端执行一次 xattr -cr /Applications/Cyte.app 即可正常启动。
