Changelog

What changed in each version of BaoCode.

2.0.5

Bug Fixes

  • Eliminated Duplicate Historical User Bubbles on Session Resume: Passes hasPrompt: true during initialize handshake and adds multi-layer filtering for startup renderHistory() bursts and stray isReplay echoes, preventing historical user messages from being re-appended at the bottom of the chat on session resume, tab wake-up, or account switch.
  • Full CodeBuddy .jsonl Session History & Sidebar Support: Parses ~/.codebuddy/projects/*.jsonl transcripts (user/assistant messages, reasoning, tool calls & results, custom titles, and per-turn consumed credits) so sessions persist cleanly across app restarts.

2.0.4

Improvements

  • WorkBuddy-Aligned Thinking Effort: Dynamically syncs get_available_models.rawModels, supporting Thinking mode toggle and Low / Medium / High / Extra High / Max intensities plus per-model credit multipliers (0.29x, 0.00x).
  • Live Account Remaining Credits: Integrates WorkBuddy's get-user-resource-summary and enterprise billing APIs to display remaining credits right on the composer toolbar pill, popover, and account settings.
  • Per-Turn & Session Credit Consumption: Displays consumed credits (消耗 x.xx 积分) in every turn footer and session context usage panel.

Bug Fixes

  • Fixed duplicate user message bubbles caused by CodeBuddy CLI generating a new UUIDv7 when echoing --replay-user-messages.

2.0.2

What's New in Cyte 2.0.2

  • Native Tencent CodeBuddy (codebuddy / cbc) Engine: Persistent multi-turn stream-json sessions supporting CN (copilot.tencent.com), Global (www.codebuddy.ai), iOA, Enterprise, and custom ~/.codebuddy/models.json models with --effort and --autocompact.
  • Multi-Account OAuth & Credit Center: Browser OAuth login for CN & Global accounts, API Key accounts (CODEBUDDY_API_KEY), Token/JSON import & export, live edition/billing checks, per-turn credit tracking, and automatic failover.
  • Refined Workbench & Multi-Platform Releases: Minimalist thin-stroke sidebar, warm unified composer card with icon-only mode picker and crisp context ring, custom theme editor, and Ed25519-signed installers for macOS, Windows, and Linux.

macOS First Launch Note: On macOS without Apple notarization, run xattr -cr /Applications/Cyte.app once in Terminal after dragging Cyte.app into Applications if Gatekeeper blocks first launch.
